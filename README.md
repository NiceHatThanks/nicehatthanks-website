# Nice Hat Thanks Website

Website source for nicehatthanks.uk.

A lightweight static site for Nice Hat Thanks and its small, local, hackable smart-home hardware projects.

## Structure

- `index.html` — homepage
- `css/style.css` — site styling
- `js/main.js` — interactive behaviour
- `images/` — product and site imagery as the project grows

## Hosting

Designed to be deployed as a static site using Cloudflare Pages, with deployments triggered from the `main` branch.
